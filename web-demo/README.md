# 知题 · 本地刷题 Demo

30 道真实题目、6 组专项练习，无需登录、无需 AI，运行时不依赖外网。

## 打开应用

当前预览地址：[http://127.0.0.1:8765](http://127.0.0.1:8765)。

重新启动时，在 macOS 双击同目录的 **启动知题.command**；或在此目录运行：

```sh
python3 start.py
```

然后用浏览器打开上面的地址。终端需保持运行，按 `Ctrl+C` 停止。需要 Python 3，不需要安装额外库。不能直接双击 `index.html` 运行，因为浏览器需要通过本地服务读取题库。若提示端口已占用，可先检查原来的预览是否仍在运行。

只监听 `127.0.0.1`，没有部署到公网，也不会在局域网共享。手机效果通过响应式窄屏展示和 `screenshots/` 截图查看，手机不能直接访问电脑的这个本地地址。

## 可以体验什么

- 图形推理、定义判断、类比推理、逻辑判断各 5 道题；两组资料分析，每组 5 道题。
- 选择答案后提交，查看原资料解析、快速解法、推理步骤与易错点。
- 提交前不展示答案、详细解法和可能泄露思路的题目标题。
- 自动收录错题，复习答对标记为“已订正”；收藏可取消。
- 练习结束显示本组正确率；同一次作答不能重复提交计分。
- 首页继续未完成的练习。新开一组会替换当前未完成组，但不会删除历史作答、错题和收藏。
- 首页底部提供确认后清空记录。

所有记录只在**当前浏览器、当前访问地址**的本地存储中。更换浏览器、切换端口、用 `localhost` 代替 `127.0.0.1` 或清理网站数据，均不会自动迁移记录。没有账号或跨设备同步。

## 重新导入与验证

日常使用无需重新导入。开发者可安装并配置 GitHub CLI（`gh`）后运行：

```sh
python3 scripts/import_questions.py
python3 scripts/verify_data.py
```

导入脚本固定仓库提交版本，保留原始题号、来源和材料关联；忽略缺选项、答案不唯一或素材缺失的候选题。导入需要联网。`scripts/verify_data.py` 无外部依赖，检查题目结构、材料分组、答案标记隔离和图片 SHA-256。

本地服务开启后，使用具有 Playwright 与 Chromium 的 Node.js 环境运行：

```sh
node scripts/test_ui.cjs
```

测试使用独立浏览器上下文，不会改变用户预览的记录。运行结果见 [TEST-RESULTS.md](TEST-RESULTS.md)，截图在 `screenshots/`。

## 实现说明

原生 HTML / CSS / JavaScript 模块与静态 JSON；没有后端或构建步骤。`localStorage` 使用 `zhiti.demo.v1` 保存带版本号的状态。客户端持有答案数据，因此该版本是学习工具，不具备考试防作弊能力。

支持 WebMCP 的浏览器中会尝试注册读取进度、开始专项、提交答案、下一题四个操作；不支持时自动跳过，不影响正常使用。独立 Chromium 自动化环境未提供原生接口；另在 Codex 内置浏览器原生 WebMCP 上下文中验证了四个工具、重复提交幂等、无效选项与专项、未提交前跳转拒绝，并回读状态确认结果。
