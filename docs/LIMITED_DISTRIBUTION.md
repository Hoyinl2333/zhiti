# Android 有限分发登记

Google 的有限分发账户适合最多 20 台授权设备的熟人分享。登记必须由应用所有者本人完成。

1. 打开 [Android Developer Console](https://developer.android.com/developer-verification/guides/limited-distribution)。
2. 使用本人 Google 账号选择 Limited Distribution。
3. 完成身份和联系信息登记。
4. 添加永久包名 `com.xiaoyunduo.zhiti`。
5. 按控制台提示登记发布签名证书指纹和授权设备。

当前直接侧载交付与这项登记彼此独立。登记完成后继续使用相同包名和发布签名。
